🛒 ShopSync — совместный список покупок
Умный менеджер покупок с поддержкой совместного использования, категорий, цен, статистики и экспорта.
Реализован на 7 языках программирования для демонстрации различных подходов к созданию совместных приложений.

🧠 Концепция
ShopSync — это не просто список покупок. Это инструмент для совместного планирования покупок в семье или команде:

✅ Добавление товаров с названием, количеством, ценой, категорией и сроком годности.

✅ Отметка о покупке — переключение статуса «куплено».

✅ Категории — группировка товаров (продукты, бытовая химия, электроника и др.).

✅ Совместное использование — обмен списком через общий файл JSON или через встроенный HTTP-сервер (в некоторых версиях).

✅ История изменений — кто и когда добавил/изменил товар (для совместной работы).

✅ Статистика — общая сумма, количество товаров, сколько куплено/осталось.

✅ Фильтрация — по категориям, статусу, поиск по названию.

✅ Шаблоны — быстрые списки для частых походов (например, «Поход в супермаркет»).

✅ Экспорт/импорт — в JSON, CSV, текстовый формат.

🚀 Как запустить
Каждая версия самодостаточна и использует локальное хранилище (файл shoplist.json).
Для совместной работы достаточно обмениваться этим файлом (или использовать облачную синхронизацию).
В некоторых версиях реализован простой HTTP-сервер для удалённого доступа.

bash
# Python (Tkinter GUI)
pip install tk
python shopping_python.py

# C++ (Qt)
qmake && make
./shopping_cpp

# Java (Swing)
javac -cp . shopping_java.java && java shopping_java

# C# (WPF)
dotnet run

# Go (консоль)
go run shopping_go.go

# Rust (консоль)
cargo build --release && ./target/release/shopping_rs

# JavaScript (Node.js + readline)
node shopping_js.js

📦 Содержимое репозитория
Файл	Язык	Особенности
shopping_python.py	Python	Tkinter GUI, автодополнение, цветовое выделение, синхронизация через общий файл
shopping_cpp.cpp	C++	Qt Widgets, таблица товаров, фильтры, экспорт в CSV
shopping_java.java	Java	Swing с JTable, диалоги для редактирования, импорт/экспорт
shopping_cs.cs	C#	WPF с DataGrid, MVVM-подход, цветовая индикация
shopping_go.go	Go	консоль с цветным выводом, команды, сохранение в JSON
shopping_rs.rs	Rust	консоль с termion, цветные таблицы, сериализация
shopping_js.js	JavaScript	Node.js + readline, интерактивный режим, автосохранение
🔮 Расширенные функции
Совместное редактирование — при использовании общего файла или встроенного сервера (для Python и JS реализован простой HTTP API).

Умные подсказки — при вводе названия предлагаются ранее использованные товары.

Автоматический подсчёт суммы и контроль бюджета.

Планирование меню — привязка товаров к дням недели (опционально).

Уведомления о приближающемся сроке годности (при запуске).
